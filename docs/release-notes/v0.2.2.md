ZeroIn 0.2.2 fixes pages that could not scroll or were cut off, centres and scales the interface for screens from 14" laptops to 55" TVs, fixes a "mouse input stopped" re-run after normal pauses, and fixes the low polling rate shown in the sidebar.

**Downloads**
- `ZeroIn-Setup-0.2.2-x64.exe`: installer, includes the local AI model (Qwen3 1.7B, Q4_K_M, about 1.1 GB).
- `ZeroIn-0.2.2-x64-portable.zip`: app only, no model. Works fully without the AI.
- `SHA256SUMS.txt`: checksums for both files.

**Fixed**
- **Scrolling.** Every page (Setup, Test, Result, History, Settings, Check mouse) scrolls with the mouse wheel, the scrollbar, Page Up / Page Down / Home / End, and follows the keyboard focus. In 0.2.1 content below the window, such as the Check mouse figures, could not be reached.
- **Cut-off text.** Headings, choice rows, settings rows and figures wrap or stack instead of running past the right edge.
- **"Mouse input stopped in the middle of a movement" after a normal pause.** A short settle after a click, a normal reaction pause and then a flick could be taken for dropped input. The rule now only counts a gap in the middle of a fast movement toward the target, with the hand fast again right after it, and measures speed in a way that is not fooled by Windows delivering reports in bursts.
- **Sidebar polling rate.** It averaged in slow movement, so a 1000 Hz mouse could show about 740 Hz. It now uses only stretches of fast movement, like Check mouse.

**Added**
- **Centred, scalable layout.** The page sits in a centred column. The interface follows the Windows display scale and, on Auto, the window size. Settings → Interface scale: Auto, 90, 100, 110, 125 or 150 %. Test results do not depend on the scale.
- Opens maximised; dialogs scroll on short windows; Rapoo added to the USB vendor table.

**Limits**
- Layout was checked with screenshots on a virtual display at 1366×768 (150 %), 1920×1080 (100 %) and 3840×2160 (200 %), plus the main screens at 16 size and scale combinations; it has not yet been checked on a real Windows display at every scale.
- The dropped-input and polling-meter fixes were verified with synthetic report streams; they have not yet been run against the reporting user's hardware.
