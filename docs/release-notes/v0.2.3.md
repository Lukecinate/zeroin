ZeroIn 0.2.3 is a reliability and safety update. Layout and test results are unchanged from 0.2.2.

**Downloads**
- `ZeroIn-Setup-0.2.3-x64.exe`: installer, includes the local AI model (Qwen3 1.7B, Q4_K_M, about 1.1 GB).
- `ZeroIn-0.2.3-x64-portable.zip`: app only, no model. Works fully without the AI.
- `SHA256SUMS.txt`: checksums for both files.

**Fixed**
- **Memory growth in the background.** Mouse and keyboard input no longer piles up while ZeroIn is open behind a game or minimized.
- **Local AI stuck on "ready".** Turning the AI off and on while it was loading could leave it showing ready without ever answering. Restarting is now safe, and a failed or slow explanation no longer shows "writing…" forever.
- **Check mouse after leaving the screen.** Switching page during a capture now cancels it, so the next test gets mouse input straight away.
- **History safety.** A damaged history file is kept under a new name and never overwritten; a file that is only locked at start-up is left alone and not saved over. Files are flushed to disk before replacing the old version.
- **Neutral pointer settings.** Changing and restoring them no longer waits on other apps' windows. Recovery after a crash only applies to the same Windows sign-in, within a day.
- **Apply to Windows** keeps the values shown when you confirm as the backup.

**Changed**
- One ZeroIn at a time; opening it again brings the existing window forward.
- The Wooting Analog SDK is loaded only from its install folder, the system folder or ZeroIn's folder (not from `PATH`).

**Limits**
- The Windows-specific changes (input thread, pointer-settings notification, single instance, sign-in detection, SDK loading) were compiled and lint-checked for Windows and covered by unit tests of their logic; they have not yet been exercised on a physical Windows PC.

See CHANGELOG.md for details.
