ZeroIn 0.1.0 is the first public release: a Windows 10/11 tool that finds the mouse sensitivity you aim best with, using blind aim drills, a deterministic search, and an optional AI model that runs entirely on your PC.

**Downloads**
- `ZeroIn-Setup-0.1.0-x64.exe`: installer, includes the local AI model (Qwen3 1.7B, Q4_K_M, about 1.1 GB).
- `ZeroIn-0.1.0-x64-portable.zip`: app only, no model. Works fully without the AI.
- `SHA256SUMS.txt`: checksums for both files.

**Highlights**
- Setup asks for your game, DPI, current sensitivity, Windows pointer precision and pointer speed, and checks the last two against Windows.
- Ten games plus custom yaw; flick, micro-adjust and tracking drills in each game's rotation scale.
- Raw Input with polling-rate measurement, uncapped drill rendering, high-refresh detection.
- Result with cm/360, eDPI and conversions to every supported game; local history.
- No accounts, no telemetry, no network access.

**Known limitations**
- Haptic mouse feedback is not implemented yet.
- The Finals, Marvel Rivals and PUBG constants are estimates.
- The local AI needs a CPU with AVX2/FMA; without it the app runs with its built-in summary.
