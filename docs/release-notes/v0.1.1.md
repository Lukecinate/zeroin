ZeroIn 0.1.1 fixes the visible cursor during drills and adds a reversible way to set neutral Windows mouse settings.

**Downloads**
- `ZeroIn-Setup-0.1.1-x64.exe`: installer, includes the local AI model (Qwen3 1.7B, Q4_K_M, about 1.1 GB).
- `ZeroIn-0.1.1-x64-portable.zip`: app only, no model. Works fully without the AI.
- `SHA256SUMS.txt`: checksums for both files.

**Fixed**
- The mouse cursor is hidden and confined to the window during drills, and released immediately on test end, Esc/pause, Alt+Tab, minimise, exit or a crash. Measurements still use Raw Input and are unchanged.
- History shows times in your local time zone instead of UTC.

**Added**
- Apply to Windows (Result screen, Settings, and the Setup warnings): sets "Enhance pointer precision" off and pointer speed 10 for your Windows account after a confirmation showing current and new values. No admin rights needed.
- Restore previous: your earlier values are saved to `%APPDATA%\ZeroIn\mouse-backup.json` before any change and can be put back. Both actions read the settings back and report the outcome.
- In-game sensitivity is never written; the Result screen shows the value to enter in the game.

See CHANGELOG.md for details.
