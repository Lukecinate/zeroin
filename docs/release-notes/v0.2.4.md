ZeroIn 0.2.4 is a security patch. Layout and test results are unchanged from 0.2.3.

**Downloads**
- `ZeroIn-Setup-0.2.4-x64.exe`: installer, includes the local AI model (Qwen3 1.7B, Q4_K_M, about 1.1 GB).
- `ZeroIn-0.2.4-x64-portable.zip`: app only, no model. Works fully without the AI.
- `SHA256SUMS.txt`: checksums for both files.

**Security**
- **Official AI model only.** The advisor loads a `.gguf` file only when it is a regular file of the expected size and its SHA-256 matches the official Qwen3 1.7B Q4_K_M file shipped in the installer. A different or substituted file is not loaded. The portable zip still works without a model; to add the advisor, place that official file in a `models` folder next to `zeroin.exe` or in `%APPDATA%\ZeroIn\models`.
- History, settings and journal files larger than 8 MiB, or that are symbolic links, are not loaded.
- Links opened in the browser must be plain `https://` addresses.
- Incomplete Raw Input reads are ignored.

**Limits**
- The Windows-specific Raw Input change was compiled and covered by unit tests of its length check; it has not been exercised on a physical Windows PC. The model SHA-256 check uses the same digest as the release workflow; it has not been run against a real model file on this machine.

See CHANGELOG.md for details.
